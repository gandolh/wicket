**Wicket** is one queue for every LLM call a small set of self-hosted apps
makes. It holds the Ollama key, gives every call a ticket in one
first-come-first-served line, and runs one call at a time. Ollama Cloud answers
first, and a small backup model on the box answers when the cloud fails.

![The Wicket queue page: now serving ticket 2, a running call answered by the backup model, two tickets waiting, calls per app and recent calls](./guides/images/hero.webp)

<dl className="doc-facts">
  <dt>Callers</dt>
  <dd>Apps with their own bearer token; today just-a-bot and ro-housing</dd>
  <dt>API</dt>
  <dd>Fastify 5 on loopback port 8808, reached at <code>/wicket-api</code></dd>
  <dt>Page</dt>
  <dd>React 19 at <code>/wicket/</code>, behind sign-in (local accounts or Ward)</dd>
  <dt>Models</dt>
  <dd>Ollama Cloud (<code>gpt-oss:120b</code>), then <code>gemma3:1b</code> in a capped container</dd>
  <dt>Stored</dt>
  <dd>Counts and timings per call, never a prompt or an answer</dd>
</dl>

![How a call moves through Wicket: apps post to wicket-api with their own token; the queue runs one call at a time on Ollama Cloud first and on the wicket-ollama backup when the cloud fails](./guides/images/architecture.svg)
